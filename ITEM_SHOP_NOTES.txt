金币道具商店与随机血包

操作
R：打开 / 关闭免费餐车升级。Tab：打开 / 关闭金币道具商店。
两个界面互斥并暂停游戏；键位可在 Global Data > Input 修改。
道具商店可在任何位置打开，允许满血或双手持物时购买。
默认 Medkit 25 金币，接触后回复 25 HP，不占双手。
购买后血包落在餐车周围的随机空地；无有效落点、余额不足或生成失败不扣金币。
满血时保留血包；站在血包上受伤仍能自动回血。死亡玩家不复活。

Designer 配置
点击场景 Global Data > Item Shop / 道具商店，展开目录和商品编辑。
通过 Assets > Create > MMFeast > Item Shop > Medkit Item 新增商品资源，加入 Catalog 的 Items 列表。
名称、说明、图标、Medkit Pickup 预制体、价格、回血量和 Listed 均可编辑。
可复制默认 Medkit.prefab 制作不同外观，保留启用的 MedkitPickup、2D Circle Trigger 和 Kinematic Rigidbody2D。
投放中心为本场景餐车，默认偏移 (0,0)、尺寸 (16,10)、额外间距 0.25、随机尝试 30 次。
落点避开餐车、等待区、角色、已有拾取物和其他启用的 2D 碰撞体，包括触发区域。
价格与投放参数影响后续购买；回血量实时影响已落地血包。
下架或从目录移除只阻止新购买，已落地血包仍可使用。
资源在 Play Mode 的修改也会保存；当前金币及地上实例属于本局状态。
免费餐车升级继续不检查、不扣除任何资源；净化食客奖励和右上角金币显示保留。
首次迁移将餐车升级改为 R，新道具商店为 Tab；后续设置工具保留 Designer 改键。
两个原型场景及所有使用 Global Data 的场景生成工具已接入。

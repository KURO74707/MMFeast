僵尸与食客性能优化报告
日期：2026-10-17
Unity：6000.6.4f1

结果
第一轮优化已实现。200 个混合 NPC（僵尸、食客各半）：
编辑器主线程平均 4.130 → 1.469 ms，P99 13.524 → 8.309 ms，最慢帧 42.846 → 12.977 ms。
开发版独立游戏主线程平均 2.190 → 0.956 ms，P99 10.183 → 6.939 ms，最慢帧 22.112 → 14.036 ms。
这些是隔离压力场景的一次成对实测，不保证正式游玩或完整交互编辑器稳定在某个 FPS。

已完成的改动
1. Global Data / Diagnostics / 普通玩法调试日志默认关闭。在格式化字符串前检查，覆盖攻击、受伤、生成、掉落、烹饪、净化等普通日志；错误、警告保留。
2. 僵尸避让使用可增长的复用结果列表和去重集合，缓存目标玩家组件。保持半径、频率、权重和邻居计算，无固定数量截断。
3. 等待区复用查询列表、刚体集合和清理谓词；移除出口临时数组；座位位置、数量和提示仅变化时更新。保留 Physics2D.SyncTransforms。
4. NPC 血条通过事件更新数值；相机、朝向仅变化时赋值。玩家、餐车 HUD 持续读取实时配置，但数值不变时不格式化文字。FPS 保留每 0.25 秒更新。
5. 刷怪器缓存实体组件，先判断生成间隔；食客缓存同场景钱包，失效后重新查找，保留场景隔离及单次奖励保护。
6. Profiler 额外发现厨房提示每帧重复解析键位显示名。增加共享配置上的键位显示缓存（输入版本、键鼠/手柄设备变化时失效），并缓存厨房状态提示。升级、道具商店的关闭键提示也复用此缓存。

关键分配来源
旧代码独立诊断中，“NPC Legacy Binding Label”直接父标记记录每帧 187,812 字节 GC 分配。
该数值属于本场景的重复调用路径；另一组预热后的独立 API 测试为 0 字节，因此不能推断所有环境中 GetBindingDisplayString 都分配约 188KB。
优化后新逻辑在输入或状态变化时更新提示，保留运行中改键及提示到期行为。

测试方法
硬件：Intel i9-14900KF（32 线程）、RTX 4090、64GB RAM。
使用相同原型场景、URP 2D 渲染、物理设置和固定随机种子，在图形开启的批处理编辑器及 Development Mono 独立游戏分别测量。D3D11、关闭 VSync、targetFrameRate=-1，请求分辨率 1280×720（编辑器实际 GameView 像素尺寸未独立核验）。
每种模式测量 20、100、200 个 NPC，纯僵尸、纯食客、各半混合共 9 组。每组预热 3 秒，采样约 30 秒；这 30 秒依次包含聚集围攻、连续生成、批量击杀/净化、安装等待区四段，每段约 7.5 秒，并非每段单独采样 30 秒。
测试通过真实刷怪、伤害、净化与等待区路径，临时克隆配置调整数量/间隔，并使用高 HP 玩家和餐车维持围攻。高 HP 浮点精度也意味着部分小额伤害不会触发血量变化事件；该夹具用于持续压力，而非逐击血条更新成本测试。
正式配置、场景、预制体和渲染设置未被覆盖。共享 GlobalGameSettings 资源哈希与原版一致；原版与最终运行时源码快照保留用于核验。
隔离工程省略无关的 AI/编辑器辅助包；编辑器结果不能等同于完整交互编辑器环境。隔离构建仅剔除当前场景未使用的后处理 shader 变体；正式工程未改动 shader 或渲染配置。
每帧主线程和 GC 数据来自原生 ProfilerRecorder。逐帧 CSV、分阶段汇总及计数器名称均保留。
采样 CSV 中 ai_mean_ms/log_mean_ms 对应的可选计数器未匹配成功，零值表示不可用，不表示没有成本。AI/日志归因使用另外录制的原始 Profiler 捕获。
所有矩阵采样结束后单独录制约 5 秒 200 混合 NPC 诊断，避免二进制写盘影响上述分数。离线分析受编辑器 2000 帧保留上限影响，诊断表注明实际读取帧数；原始文件保留完整捕获。
记录器帧列表初始容量 65536，在优化后最高帧率的早期 20 NPC 分组发生扩容。因此部分低负载分组含夹具记录缓冲区分配，所有原始尖峰保留，未选择性剔除；200 NPC 组在缓冲区预热之后执行。
同一组原版/最终版附加相同 NPC Profiler 标记；正式运行时代码没有这些测试标记。LegacyLabelDiagnostic 为独立归因诊断，不属于正式成对成绩。FirstPass 为发现键位缓存问题前的中间结果，也不作为最终成绩。

仍存在的热点
最终独立游戏诊断（读取 2000 主线程帧）：
- UGUI.Rendering.UpdateBatches：平均自身耗时 0.142 ms/帧。
- UGUI.Rendering.EmitWorldScreenspaceCameraGeometry：平均自身耗时 0.065 ms/帧。
- Physics2D.Simulate：平均包含子调用 0.223 ms/帧，P99 5.099 ms，最大 6.673 ms。
- 连续碰撞相关两个自身标记平均分别约 0.066、0.055 ms/帧。
- NPC Separation：平均包含子调用 0.078 ms/帧，P99 1.547 ms。
- Instantiate 单帧最高包含耗时约 1.518 ms；该诊断出现一次 GC.Collect，最大 0.534 ms。
包含子调用的标记有嵌套关系，不可直接相加。原生标记仍可能名为 Physics2D.OverlapCircleAll，这不代表新的 C# 列表查询创建了结果数组。
关闭普通日志后，该诊断 LogStringToConsole 调用数为 0。
全场景仍有生成/初始化和 UI 等分配。复用缓冲区稳定后查询本身无逐次分配，不等于整个游戏零 GC。
后续如继续优化，优先复核大量世界空间血条的批处理/几何开销及密集连续碰撞。是否引入对象池应根据实际生成尖峰再决定。本轮没有改变碰撞检测模式、碰撞矩阵或 AI 更新频率。

功能验证
18 组共 975 项检查全部通过，其中新增 NPC 优化检查 227 项。
覆盖密集避让、超过 200 个结果不截断、触发器筛选、目标缓存、等待区阻挡/搬动、血量事件、实时调参、输入缓存失效、提示到期、净化金币场景隔离与重复奖励、暂停及 FPS。
预热后分别连续 1000 次调用：避让、空等待区阻挡检查、未变化 HUD、未变化厨房提示均测得 0 字节托管分配。
旧战斗验证夹具显式启用日志，并在隔离配置使用其历史断言所需数值；正式调参未修改。不存在通过修改正式数值来让旧测试通过的情况。
批处理编辑器启动出现已有辅助包异常，不在游戏采样区间；所有最终验证、构建及矩阵运行退出成功。未进行人工画面逐帧验收。
